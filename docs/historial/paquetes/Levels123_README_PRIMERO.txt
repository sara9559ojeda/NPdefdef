NEUROPHOBIA - PAQUETE NIVELES 1, 2 Y 3

1. Cierra Unity.
2. Descomprime este ZIP dentro de C:\NeuroPhobia\. Debe combinarse con la carpeta Assets existente.
3. Abre Unity y espera a que termine de importar y compilar.
4. En Unity abre: Tools > NeuroPhobia > Validar archivos Niveles 1-3.
5. Luego abre: Tools > NeuroPhobia > Reconfigurar Niveles 1-3.
6. Unity crea copias de seguridad de las tres escenas antes de cambiarlas.

PRUEBA EN COMPUTADOR
- WASD: caminar
- Mouse: mirar
- Shift: correr
- Escape: liberar o capturar el cursor
- R: volver al punto inicial
- Enter: pulsar el botón Continuar cuando esté visible

IMPORTANTE
- No reemplaza Assets/XR, Assets/XRI, Assets/Settings, Assets/Samples ni TextMesh Pro.
- No incluye narración hablada del Nivel 1 ni la voz narrativa de calma del Nivel 3. Esas grabaciones siguen pendientes de la autora.
- No publiques esta carpeta como un paquete de assets independiente. Úsala dentro del proyecto NeuroPhobia y conserva los créditos.
